# Prompt: Update SRS with Responsibility Statement

## Role
You are the **producer** of the SRS change.

## Task
Update the SRS according to the approved change request.

## Rules (MUST)
- You **MUST** preserve the SRS structure.
- You **MUST** ensure the document is format-valid and checkable.
- You **MUST NOT** assume audit approval.
- You **MUST** generate a Change Analysis Report (CAR) as a responsibility statement.
- You **MUST NOT** generate an Acceptance Change Report (ACR).

## Input
### Change Request
<<<
Describe the approved change.
>>>

### Existing SRS
<<<
Paste the current SRS here.
>>>

## Output
- Updated SRS (Markdown)
- CAR (Markdown, responsibility statement only)
