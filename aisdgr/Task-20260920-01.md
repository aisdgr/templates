## 備註

**核心洞察：**
- Rule 的價值在於可重用性
- 可重用性只存在於「行為約束」，不在於「內容規則」
- Core = Decision Behavior Constraint
- Domain = Artifact-specific constraint
- Ruleset = 唯一組合點

**下一步行動：**
1. 優先完成 Core Rule 壓縮（最關鍵）
2. SPEC Domain 重寫（取代 DOCS）
3. Rule ID v3 簡化（可市場化）
