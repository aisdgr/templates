## 架構概覽

### 域層 (Domain Layer)

- **CORE**: 適用於所有製品類型的跨域共享規則
- **CODE**: CORE 之外的代碼特定規則
- **DOCS**: 文檔特定規則
- **LANG**: 語言特定的編碼標準（應用域維度）
- **GOV**: 治理原則和執行

### 行為約束類別層 (Behavior Constraint Category Layer)

- **AR**: 製品隔離 (Artifact Isolation)
- **BD**: 邊界與停止 (Boundary & Stop)
- **CN**: 約束中立性 (Constraint Neutrality)
- **LG**: 日誌與報告 (Logging & Report)
- **ST**: 結構變更 (Structural Change)
- **TI**: 測試完整性 (Test Integrity)
- **TR**: 可追溯性 (Traceability)
- **ENF**: 執行 (Enforcement，GOV 特殊類別)
- **PR**: 原則 (Principles，GOV 特殊類別)

### 規則 ID 格式

```
{DOMAIN}-{CATEGORY}-{SUBTYPE}-{NUMBER}
```

- **DOMAIN**: CORE | CODE | DOCS | LANG | GOV
- **CATEGORY**: AR | BD | CN | LG | ST | TI | TR | ENF | PR
- **SUBTYPE**: C (約束) | P (策略) | 語言代碼 (GO, JV, JS, PY, RS, TS, STD)
- **NUMBER**: 001-099 (核心), 100-199 (擴展)
