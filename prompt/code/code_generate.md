# Code Generate Pattern

Goal:
Generate source code according to the Code Scope defined in VDP.

Constraints:
- Generation only
- Do NOT validate
- Do NOT run tests
- Do NOT assume correctness
- Do NOT generate TR
- Do NOT commit

Inputs:
- VDP.md (Code Scope section)
- SRS.md
- SDS.md

Output:
- Source code under src/

Responsibility:
- Producer only
- No verification or approval is implied
