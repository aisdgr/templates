# Test Report (TR) Generate Pattern

Goal:
Generate Test Report (TR) by summarizing actual test execution results.

Constraints:
- Reporting only
- Do NOT execute tests
- Do NOT modify source code or test code
- Do NOT declare responsibility
- Do NOT approve results

Inputs:
- STS.md
- Test execution outputs (logs, result files)

Output:
- reports/TR.md

Responsibility:
- Producer only
- TR reflects execution facts, not validation or approval
